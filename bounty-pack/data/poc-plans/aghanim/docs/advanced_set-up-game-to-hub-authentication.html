Set up Game-to-Hub authentication

To allow players to log in into the game hub using their Player ID:

  1. Determine the existed in-game parameter to be used as the Player ID.
  2. To interact with the game hub, implement the player.verify webhook.
  3. Embed a deep link within your game client.
  4. Instruct the players on the location of their authentication data.
